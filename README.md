# Customer-churn-analysis
## Project Overview
This Project analyzes customer churn using python and data visualization techniques. The goal is to identify patterns and 
customer churn.
## Dataset 
The dataset contains customer information such as:
-customer tenure
-contract type
-internet service
-monthly charges
etc.

# Language use:
Python,
Pandas,
NumPy,
Matplotlib,
Seaborn,
Jupyter Notebook.

# Project Workflow
1. Data Loading
2. Data Understanding
3. Data Cleaning
4. Exploratory Data Analysis(EDA)
5. Churn Analysis
6. Data Visualization
7. Business Insights

# Key Analysis
The project analyzes churn pattern based on:
- customer type
- customer tenure
- internet service
- payment method

# Conclusion
The analysis helped identify customer segments and service- related patterns associated with churn. These insights
can help businesses understand customer behavior and design better retention strategies.
